# 🚀 GitHub Profile README Setup Guide

This guide will help you set up your world-class GitHub Profile README.

## 📋 Prerequisites

- GitHub account (username: `kathirvel-p22`)
- Repository named `kathirvel-p22` (same as your username)
- GitHub Actions enabled

## 🛠️ Installation Steps

### Step 1: Create Profile Repository

1. Go to GitHub and create a new repository
2. Name it exactly: `kathirvel-p22` (your GitHub username)
3. Make it **PUBLIC**
4. Initialize with README (or upload the README.md file)

### Step 2: Upload Files

Upload these files to your repository:

```
kathirvel-p22/
├── README.md                    # Main profile README
└── .github/
    └── workflows/
        └── snake.yml           # Snake animation workflow
```

### Step 3: Enable GitHub Actions

1. Go to your repository settings
2. Navigate to **Actions** → **General**
3. Enable **Read and write permissions** for workflows
4. Save changes

### Step 4: Customize Personal Information

Update the following placeholders in README.md:

- **LinkedIn**: Replace `https://linkedin.com/in/kathirvel-p` with your actual LinkedIn URL
- **Email**: Replace `kathirvel.dev@example.com` with your real email
- **Portfolio**: Add your portfolio website URL
- **Resume**: Add link to your resume PDF
- **Social Media**: Update Twitter, Medium, Dev.to, Hashnode handles
- **LeetCode/HackerRank**: Add your profile links

### Step 5: Trigger Snake Animation

1. Go to **Actions** tab in your repository
2. Select "Generate Snake Animation" workflow
3. Click **Run workflow**
4. Wait for completion (takes ~1 minute)

## 🐛 Troubleshooting

### Snake Animation Not Showing

1. Check if Actions workflow ran successfully
2. Verify `output` branch exists
3. Wait 5-10 minutes for GitHub to update
4. Clear browser cache

### Stats Not Loading

1. Check if username is correct
2. Try different theme options
3. Ensure repository is public
4. Check API rate limits

### Images Not Displaying

1. Verify image URLs are accessible
2. Check file paths are correct
3. Ensure repository is public
4. Try different CDN services
